# Reading Time Estimator

A writing utility for estimating article reading duration.

## Features

- Word count
- Adjustable reading speed
- Estimated reading time

## How to Use

Paste an article and choose a reading speed.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Paste a sample paragraph and verify its word count.
- [ ] Change reading speed and inspect the estimated duration.
- [ ] Clear the paragraph and verify the statistics reset.
